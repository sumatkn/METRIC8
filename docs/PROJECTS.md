## Adding a project

Use [the project template](../templates/project/README.md) under `addons/<project-id>/` or `tools/<project-id>/`. Register its purpose, status, owner or maintainer when known, source location, and distribution location.

Suggested status vocabulary: candidate, requirements, implementation, testing, released, paused, archived. Use only a status supported by evidence.
