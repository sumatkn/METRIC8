# METRIC8 suite scope

## Confirmed foundation

METRIC8 is the overarching suite repository for WoW: Forever addons and supporting tools. Its guiding description is **Simple. Informational. Minimalistic.**

The suite owns:

- The overall purpose and boundaries.
- A project list with each project's status and location.
- Rules of engagement and an explicit procedure approval register.
- Shared decisions and working memory.
- A consistent place for every project's source, documentation, assets, and packaged files.

Each addon or tool owns its specific requirements, behavior, implementation, compatibility notes, validation, documentation, and distributable files.

## Boundaries

This setup establishes organization and documentation. It does not implement addons, import earlier files, select a WoW client API version, or establish a shared runtime.

A project being discussed does not automatically make it an approved suite component. Candidate inclusion is recorded in the project list.

## Open suite decisions

- Final initial project roster and product names.
- Whether the suite will eventually have an installer, launcher, shared settings, or shared runtime.
- Supported client builds and compatibility policy, once verified.
- Release hosting, versioning, and review workflow; see [procedures](PROCEDURES.md).

Do not resolve these by inventing requirements during unrelated work.
